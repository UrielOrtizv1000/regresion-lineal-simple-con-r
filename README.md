# Regresión lineal simple con R

Repositorio académico para resolver ejercicios de regresión lineal simple utilizando el lenguaje de programación R.

## Objetivo

Aplicar los conceptos fundamentales de regresión lineal simple mediante ejercicios relacionados con ingeniería, sistemas computacionales, producción, consumo de energía y análisis de datos.

## Contenido

El proyecto incluirá:

* Diagramas de dispersión.
* Estimación de modelos de regresión lineal.
* Cálculo e interpretación de los coeficientes β₀ y β₁.
* Coeficiente de correlación de Pearson.
* Coeficiente de determinación R².
* Pruebas de hipótesis.
* Análisis de varianza.
* Intervalos de confianza.
* Intervalos de predicción.
* Estimaciones puntuales.
* Análisis gráfico de residuos.
* Interpretación de resultados.
